TITLE
OSF UI - Web Interface Framework

SHORT DESCRIPTION
An SFSE framework for custom menus and HUDs built with HTML, CSS, and JavaScript, connected to C++ or Papyrus. WebView2 is the recommended default; CEF is the bundled-runtime alternative. Requires OSF Settings. Install one edition.

VERSION
2.1.0

CHANGELOG
- Added separate WebView2 and bundled CEF editions with automatic backend selection and the same game DLL and public APIs.
- Refined CEF damage copying, publication scheduling, and view reveal handling while retaining safe texture completion and full-copy fallbacks.
- Added mixed menu/HUD/overlay validation; measured performance varies by workload and does not establish a general CEF speed or memory improvement.
- Product version 2.1.0 retains native API 2.0, browser protocol 2, and the documented legacy compatibility interfaces.

WEBVIEW2 FILE TITLE
OSF UI 2.1 - WebView2 (Recommended Default)

WEBVIEW2 ARCHIVE
Use the archive ending in -webview2.zip. Current local candidate: OSF-UI-v2.1.0-webview2.zip.

WEBVIEW2 FILE DESCRIPTION
Recommended default: smaller download and lower measured CPU/memory overhead. Requires WebView2 Evergreen, SFSE, Address Library, and OSF Settings. Renderer selected automatically. Install one edition only; both share the same DLL and mod APIs.

CEF FILE TITLE
OSF UI 2.1 - CEF (Bundled-Runtime Alternative)

CEF ARCHIVE
Use the archive ending in -cef.zip. Current local candidate: OSF-UI-v2.1.0-cef.zip.

CEF FILE DESCRIPTION
Bundled-runtime alternative with Chromium included; no WebView2 required. Larger download and higher measured CPU/memory overhead. Requires SFSE, Address Library, and OSF Settings. Renderer selected automatically. Install one edition only.
