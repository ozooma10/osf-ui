TITLE
OSF UI - Web Interface Framework

SHORT DESCRIPTION
An SFSE framework for custom menus and HUDs built with HTML, CSS, and JavaScript, connected to C++ or Papyrus. WebView2 is the recommended default; CEF is the bundled-runtime alternative. Requires OSF Settings. Install one edition.

VERSION
2.1.0

CHANGELOG
- Added optional F11 performance diagnostics in Developer mode: browser timing on both editions, plus capture/publication timing and correlated hitch logs on WebView2. Developer mode is off by default and requires a restart.
- Guarded WebView2 capture timing while views are visible and improved browser-host recovery without blocking the game tick.
- Added separate WebView2 and bundled CEF editions with automatic renderer selection and the same public APIs.
- Refined CEF damage copying, publication scheduling, and view reveal handling while retaining safe texture completion and full-copy fallbacks.
- Prevented CEF from publishing an empty first frame while a menu waits for its reveal paint; healthy views continue updating while other views load.
- Added mixed menu/HUD/overlay validation; measured performance varies by workload and does not establish a general CEF speed or memory improvement.
- Fixed missed repeated hotkeys after closing an overlay and blank first menu presentation during a Settings launcher handoff.
- Improved browser recovery and CEF view isolation, bounded message queues, graceful shutdown, GPU selection, and local media seeking.
- Product version 2.1.0 retains native API 2.0, browser protocol 2, and the documented legacy compatibility interfaces.

WEBVIEW2 FILE TITLE
OSF UI 2.1 - WebView2 (Recommended Default)

WEBVIEW2 ARCHIVE
Use the archive ending in -webview2.zip. Current local candidate: OSF-UI-v2.1.0-webview2.zip.

WEBVIEW2 FILE DESCRIPTION
Recommended default: smaller download and lower measured CPU/memory overhead. Requires WebView2 Evergreen, SFSE, Address Library, and OSF Settings. Renderer selected by the installed edition. Install one edition only; both provide the same mod APIs.

CEF FILE TITLE
OSF UI 2.1 - CEF (Bundled-Runtime Alternative)

CEF ARCHIVE
Use the archive ending in -cef.zip. Current local candidate: OSF-UI-v2.1.0-cef.zip.

CEF FILE DESCRIPTION
Bundled-runtime alternative with Chromium included; no WebView2 required. Larger download and higher measured CPU/memory overhead. Requires SFSE, Address Library, and OSF Settings. Renderer selected by the installed edition. Install one edition only.
