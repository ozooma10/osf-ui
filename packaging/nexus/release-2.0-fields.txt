TITLE
OSF UI - Web Interface Framework

SHORT DESCRIPTION
An SFSE framework for custom menus and HUDs built with HTML, CSS, and JavaScript, connected to C++ or Papyrus. WebView2 is the recommended default; CEF is the bundled-runtime alternative. Requires OSF Settings. Install one edition.

VERSION
2.0.0

CHANGELOG
- Moved mod configuration, keybindings, and issue reporting to the separate OSF Settings framework. OSF Settings is now required.
- Mod menus can register with the Launcher in OSF Settings.
- Added a new 2.0 API for custom menus, passive HUDs, and communication between web interfaces and C++ or Papyrus.
- Included a compatibility adapter for the documented 1.6 interfaces, preserving supported mods' existing files and saved values.
- Two automatically selected browser editions share the same game DLL and public APIs: WebView2 (recommended default) and CEF (bundled-runtime alternative).
- The selected browser helper starts when a view is requested.

WEBVIEW2 FILE TITLE
OSF UI 2.0 - WebView2 (Recommended Default)

WEBVIEW2 ARCHIVE
Use the archive ending in -webview2.zip. Current local candidate: OSF-UI-v2.0.0-rc-webview2.zip.

WEBVIEW2 FILE DESCRIPTION
Recommended default: smaller download and lower measured CPU/memory overhead. Requires WebView2 Evergreen, SFSE, Address Library, and OSF Settings. Renderer selected automatically. Install one edition only; both share the same DLL and mod APIs.

CEF FILE TITLE
OSF UI 2.0 - CEF (Bundled-Runtime Alternative)

CEF ARCHIVE
Use the archive ending in -cef.zip. Current local candidate: OSF-UI-v2.0.0-rc-cef.zip.

CEF FILE DESCRIPTION
Bundled-runtime alternative with Chromium included; no WebView2 required. Larger download and higher measured CPU/memory overhead. Requires SFSE, Address Library, and OSF Settings. Renderer selected automatically. Install one edition only.
