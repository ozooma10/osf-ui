# Project templates

The supported presets are `menu-papyrus` and `menu-native`. Both emit directly
deployable files at `mod/Data/SFSE/Plugins/OSF/UI/views/<mod>/<view>/` and use the
OSF UI 2 bridge: `send`, `request`, transient events, and retained state.

Settings templates do not belong here. They are owned by the independent OSF
Settings project.
